# Фоновая служба ZapretGUI

`resources/background_service/ZapretGUI.Service.exe` — доверенный вспомогательный компонент для операций, которым требуются повышенные права. Служба запускает `winws` без видимого консольного окна, управляет его процессом и завершает дерево процессов при остановке или потере соединения с GUI.

## Исходники и сборка

- C#-исходник: `tools/background_service/Service.cs`.
- Скрипт сборки: `tools/background_service/build.py`.
- Готовый файл: `resources/background_service/ZapretGUI.Service.exe`.

`tools/build_release.py` сначала собирает helper, затем выполняет preflight-проверку и только после этого упаковывает приложение. Для компиляции используется системный C#-компилятор .NET Framework (`csc.exe`); при отсутствии подходящего toolchain сборка завершается с ошибкой.

## Модель безопасности

GUI работает без повышенных прав и передаёт службе команды через JSON IPC по именованному каналу. Helper проверяет клиента, протокол, fingerprint исполняемого файла `winws`, разрешённые операции и переданные аргументы. Произвольный запуск программ и выполнение shell-команд не поддерживаются.

Файлы профиля сначала читаются непривилегированным Python-клиентом, затем передаются службе через IPC. Настройки управляемых Telegram hosts встраиваются в helper как доверенный ресурс во время сборки.

Клиентская часть находится в `src/bypass_service.py`. Установка и подключение службы выполняются через `_ensure_background_service()`, а проверки протокола, аргументов, файлов и жизненного цикла находятся в `tests/test_bypass_service.py`.
