# Автозапуск 3.0.0: исправленная сборка

GUI регистрируется для текущего пользователя в
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, значение `ZapretGUI`.
Программа запускается при входе пользователя в Windows, не до входа.
Планировщик как параллельный способ запуска не используется: он обходил бы
отключение записи Run в Диспетчере задач и создавал бы дубликаты.

## Исправления

- Ошибка установки службы или отказ в UAC больше не удаляет автозапуск GUI.
- Обычный запуск GUI больше не инициирует установку службы из-за одной лишь
  включённой автозагрузки. Установка остаётся при явном включении в настройках
  и при запуске обхода.
- Автоматический запуск выбранного профиля использует имеющиеся списки, не
  ожидая сетевой синхронизации. Синхронизация начинается после запуска обхода.
- Без доступного системного трея окно не скрывается.
- Повторный автозапуск не разворачивает уже запущенный экземпляр.
- Запись Run проверяется чтением после записи. Слишком длинная команда
  (более 260 символов) вызывает понятную ошибку вместо тихой регистрации.
- Проверяются известные состояния отключения StartupApproved и флаг
  совместимости RUNASADMIN. Они **не изменяются автоматически**.
- Исправлено quoting путей при запуске/откате обновления через PowerShell.

## Установка поверх старой 3.0.0

Версия не увеличена, поэтому уже установленная 3.0.0 может не предложить
автоматическое обновление. Нужно вручную скачать новый ZIP, закрыть программу,
заменить EXE в постоянном локальном каталоге, запустить его вручную и
выключить/включить автозагрузку в настройках. Если прошлый сбой установки службы
уже выключил настройку, она не включается без согласия пользователя.

Не включайте «Запускать от имени администратора» для GUI в свойствах
совместимости EXE; повышенные права нужны отдельной службе.
Проверьте разрешение автозагрузки в Диспетчере задач.

## Если после повторного входа программа не появилась

1. Проверить наличие EXE по пути в Run:
   `reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v ZapretGUI`.
2. Проверить значок в трее и процессы в Диспетчере задач.
3. Прислать журнал `%LOCALAPPDATA%\ZapretGUI\logs\startup.log`
   (он может содержать имя пользователя и локальные пути).
4. Если после входа в журнале нет новой записи Bootstrap, до Python-кода
   выполнение не дошло: проверить StartupApproved, совместимость EXE, доступность
   диска, журнал защиты антивируса и системные политики. Сбой onefile-загрузчика
   до запуска Python также не попадёт в этот журнал.

Журнал ограничен по размеру; необработанные исключения и этапы запуска
записываются до загрузки Qt и файлов настроек. Это не гарантия запуска при
блокировке Windows/антивирусом или с отсутствующим EXE.

## Проверка сборки без изменения системы

`ZapretGUI.exe --startup-self-test <абсолютный-путь-к-json>`
проверяет загрузку onefile, основных импортов и цикл событий Qt, записывает JSON
и завершается без регистрации автозапуска, настройки службы или миграции runtime.
Это **не** эмуляция входа пользователя и не проверка автозапуска через Explorer.
